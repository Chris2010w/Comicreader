# Comic Reader (iOS)

Εφαρμογή ανάγνωσης comics (CBZ + PDF) με page-curl animation, Face ID και welcome animation.

## Πώς βγαίνει το IPA
1. Ανέβασε ΟΛΑ τα αρχεία (συμπεριλαμβανομένου του φακέλου `.github`) σε νέο repository στο GitHub.
2. Πήγαινε στο tab **Actions** → **Build IPA** → **Run workflow** (ή απλά κάνε push).
3. Όταν τελειώσει (~5-8 λεπτά), άνοιξε το run και κατέβασε το artifact **ComicReader-IPA**.
4. Το IPA είναι unsigned: κάνε το sideload με Sideloadly (https://sideloadly.io) ή AltStore (https://altstore.io).
